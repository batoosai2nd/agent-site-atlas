# 入口与访问环境

上海大学图书馆首页提供“资源发现”“馆藏目录”“数据库”“电子期刊”“电子图书”和“硕博士论文查询”等入口。实测“资源发现”打开超星发现检索结果，书目与数据库导航在 `findshu.libsp.cn`。[图书馆首页](https://lib.shu.edu.cn/index.htm) · [馆藏平台](https://findshu.libsp.cn/#/Home)

| 目标 | 入口 |
| --- | --- |
| 多类型文献检索、论文获取来源 | 首页“资源发现” |
| 书目与单册馆藏 | 首页“馆藏目录”或馆藏平台“书目检索” |
| 数据库名称、说明及访问方式 | “资源 → 电子资源 → 数据库导航” |
| 电子期刊 | “电子期刊导航”，本次仅观察到入口 |
| 个人借阅服务 | “我的图书馆”，本次未操作借还与续借 |
| 远程访问 | “校外访问”说明 |
| 馆外文献 | “服务 → 馆际互借/文献传递” |

实测日期为 2026-11-18，环境为 Windows Chrome、中文界面、已有学校访问与读者登录状态。超星发现显示上海大学机构欢迎信息，馆藏平台显示已登录读者标识。这些状态只用于核对当前访问环境。

已完成图书馆首页到超星论文 PDF 的链路，馆藏书目到单册位置的读取，以及数据库导航到说明页的定位。ScienceDirect 的 CARSI 入口实际跳转后显示人机验证，机构认证及出版商全文分支尚未完成。校外访问和文献传递步骤依据官网说明，未提交申请。

馆藏平台使用 `#/` 路由。书目和数据库详情通常新开标签页，结果列表可能留在原标签页。页面里的收录范围描述数据库内容，学校对具体资源的访问能力还需在全文页验证。

2026-11-18 独立新上下文试用以 ISBN `978-7-302-53234-7` 在默认任意词模式检索，命中《机器学习：原理、算法与应用》一条书目，并核对宝山流通库、索书号 `TP181/L23J`、在架与可借状态。未提交预约。
