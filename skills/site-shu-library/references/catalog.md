# 书目与单册馆藏

输入为书名、作者、ISBN 或主题。完成标准是识别正确版本，并读取具体单册的馆藏地、索书号、书刊状态和借阅属性。

1. 从馆藏平台首页的“书目检索”文本框输入查询，按 Enter。实测得到检索结果页。[馆藏平台](https://findshu.libsp.cn/#/Home)
2. 结果页顶部有检索字段、匹配方式、输入框和“结果中检索”开关。默认实测为“全部检索（任意词）”与“任意匹配”。精确定位特定版本时根据当前控件选择题名、责任者或 ISBN，并核对实际选中值。
3. 列表提供题名、责任者、出版社、年份、ISBN、索书号及“纸本 / 可借”汇总。左侧聚类包括资源类型、校区、馆藏地、主题、责任者和语种。
4. 点击目标书目标题，切换到新开的详情页。顶部“基本信息”可核对完整题名、版本与出版信息。
5. 在“馆藏信息 → 纸本馆藏”表中读取单册。关键列为索书号、馆藏地、书刊状态和借阅属性。实测一条记录同时显示“宝山校区-宝山流通库”“在架”“可借”。
6. 向用户报告查询时间和对应校区。列表的可借总数用于初筛，详情表用于确定实际取书位置。

详情还显示“委托/预约”和“请求”。用户需要借阅请求时，核对馆藏、取书要求与页面表单后再按授权处理。此次研究止于馆藏查询。

2026-11-18 已用书名查询打开一条书目，并核对出版信息及一册在架可借馆藏。筛选开关、预约、续借与电子书全文未实测。
