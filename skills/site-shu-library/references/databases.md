# 数据库导航与机构入口

输入为数据库名称、期刊名称或学科需求。查数据库名称时使用导航页的专用搜索框。[数据库导航](https://findshu.libsp.cn/#/dataBaseNav)

1. 在“请输入数据库名称进行检索”文本框输入名称，点击“检索”。实测 `ScienceDirect` 返回一条数据库记录。
2. 列表可展示 CARSI、OpenURL 等访问标签，以及语种和收录资料类型。页面另有正式/试用、免费/收费、首字母、学科和语种等筛选入口。
3. 点击数据库标题，在新标签页查看详情。详情包括生产商、内容层级、数据库语种、收录资料类型、收录范围、学科、访问方式和操作指南。
4. 使用“访问方式”中的实际可点击项目。实测 `CARSI` 为文本样式的控件，可以通过精确文本定位。点击后新开出版商页面。
5. 在出版商页面确认机构访问和具体文献权限。数据库详情中的总体收录年份只能说明库的内容范围，核对可下载文献仍需进入当前文献页。

2026-11-18 已完成 ScienceDirect 名称检索、详情阅读与 CARSI 跳转。落地页面为 ScienceDirect 人机验证页，因此此次没有确认后续学校认证或出版社全文下载。处理验证码时由用户按浏览器要求完成，再继续原任务。

官网另提供 CARSI 统一入口和学校 VPN 入口，具体选择见[访问与文献服务](access-delivery.md)。
