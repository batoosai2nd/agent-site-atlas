# 从图书馆查论文并取得全文

输入为论文标题、DOI 或主题。完成标准是核对题录，并取得可解析且对应目标论文的本地文件。

1. 在图书馆首页选择“资源发现”，输入主题或标题并检索。实测该区域的表单为 `#form_res`，文本框支持 Enter。结果在 `www.zhizhen.com` 新标签页打开。[图书馆首页](https://lib.shu.edu.cn/index.htm)
2. 核对发现平台顶部的机构提示，以及当前检索词、文献类型和筛选项。主题检索可先点击“期刊”限定论文。勾选“检索馆藏电子资源”等分面后，需要点击“执行限定筛选”才应用条件。
3. 按题名、作者、年份和刊名核对结果，再点击标题打开详情。详情的“获取途径”可能同时提供超星 `HTML`、`PDF`、`CNKI(包库)`、`万方(包库)`和“文献传递”。
4. 对提供 PDF 的目标论文，点击对应 PDF 链接。实测该点击直接保存文件，详情页保持原样，不能只凭没有新页面判断失败。检查浏览器下载或本地文件。
5. 核对 PDF 能否解析、页数和论文身份。题录与 PDF 的卷期、页码或 DOI 可以交叉确认。
6. 需要指定数据库时，从图书馆数据库导航进入其学校访问方式。若所有可用全文来源均未取得原文，再依据官网的文献传递服务处理。[数据库导航](https://findshu.libsp.cn/#/dataBaseNav) · [文献传递](https://lib.shu.edu.cn/fuwu/gjhj_wxcd/gjhjhwxcdfw.htm)

## 精确 DOI 查询

超星发现“高级检索”的字段下拉框支持 DOI。选择 DOI 后，实测匹配方式自动为“精确”。在第一行输入完整 DOI，再点击“检索”。高级检索会继承已有的文献类型和馆藏限制，应确认这些条件符合任务。

同一 DOI 可能命中中英文两条题录。按 DOI、作者和卷期页码判断是否为同一论文，再选择提供目标全文的条目。

2026-11-18 实测使用主题查询定位一篇《电源学报》论文，完成从图书馆首页、发现结果、详情 PDF 到本地文件的链路。PDF 为 1,610,377 字节，可解析为 11 页，文内 DOI 与后续精确检索一致。该结果验证了这一代表性论文的获取路径。
