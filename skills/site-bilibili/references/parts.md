# Parts and collections

Start with a course or multi-part upload and the requested part name or number.

1. Inspect the sidebar beside the player. The sampled course appeared inside a broader collection named `材料领域`, with its own progress count, `展开合集详情` and `展开全部合集小节` controls.
2. Locate the current upload's part titles and adjacent durations. The tested list exposed seven parts under the course title, followed by other uploads in the collection. Match the requested part within the current course.
3. Select the named part. Choosing `2.2 锂离子电池测试技术` updated the same tab to `p=2` under BV ID `BV1Zi4y1x7b5`. The tab title changed to the selected part and the player showed 53 minutes 22 seconds.
4. Confirm the current BV ID and part parameter after navigation. A different collection item can represent a different upload, so read its identity before continuing. Report both the upload title and the selected part title when needed.
5. Use the current part's player duration for segment coverage. The search card for this upload showed a total duration of 6 hours 3 minutes 5 seconds, while the first player part lasted 1 hour 6 minutes 58 seconds. Preserve `p=2` in a link intended to reopen the second part.

Completion requires the intended part to be selected and identified by the current page. A collection count describes the containing collection and can differ from the number of parts in the current upload.
