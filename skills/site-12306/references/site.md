# 网站与验证环境

## 范围

2026-11-16 在 Windows Chrome 中文桌面站、已有登录会话中完成直达车次查询、准确出发站筛选和席别价格读取。中转查询的两个正常入口均回到了个人中心，记录为部分验证。

首页位于 [中国铁路 12306](https://www.12306.cn/index/index.html)，车次结果通常进入 kyfw.12306.cn 的新标签页。主页有单程、往返、中转换乘和退改签查询入口。

## 页面特征

- 出发地、到达地使用带建议列表的输入控件。输入文字后须选择正确的站名，并检查实际选中结果。
- 首页的不同查询模式拥有独立字段，切换模式后重新核对日期和站名。
- 即使输入准确车站，结果也可能包括同城其他站。出发车站和到达车站筛选决定最终范围。
- 席别单元格的无障碍名称可能同时包含车次、票价和余票，可用于从表格中准确读取价格。
- 登录会话能够显示个人中心，仍需以查询结果本身判断车次检索成功。

预售期、余票与票价随当前日期和库存变化。操作时使用页面可选日期和最新结果。
