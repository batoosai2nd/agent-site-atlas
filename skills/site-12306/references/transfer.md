# 中转换乘入口

## 输入与完成标准

输入出发站、到达站和日期。成功的中转查询应展示具体中转站及两段车次，并能核对换乘间隔。当前环境尚未到达该结果。

## 已观察路径

1. 直达结果页出现“中转换乘”入口。研究时存在两处同名链接，分别位于观察到的 #lc_msg 和 #jxhc_alert 区域，需结合上下文限定目标。
2. 从直达结果提示中的“中转换乘”点击后，页面回到已登录个人中心。
3. 独立回到首页，切换“中转换乘”模式。该模式的站名和日期字段独立，需重新填写。
4. 输入北京南至上海虹桥、2026-11-20 并提交，打开的新标签页仍回到个人中心。

## 对任务的影响

2026-11-16 两个入口都只到达个人中心，证据为 live-partial。个人中心没有中转方案时，应记录当前最后一步和实际地址，告知用户该查询尚未完成。后续在用户恢复可用访问环境后，可从首页模式重新核对。

本指南可帮助识别入口和失败状态。两段车次比较、换乘时间与中转出票仍待实测。
