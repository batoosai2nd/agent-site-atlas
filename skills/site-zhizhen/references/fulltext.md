# 论文详情与全文获取

输入为已定位的论文。完成标准是取得可解析且对应目标论文的本地全文。

1. 从检索结果点击题名，切换到新开的详情页。核对题名、作者、期刊、年份、卷号、期号和页码。摘要截断时有“全部展开”入口。
2. 在“获取途径”选择当前可用来源。实测一篇期刊论文提供超星 HTML、PDF、`CNKI(包库)`、`万方(包库)`及“文献传递”。
3. 点击 PDF。图标和链接文字可能组合成可访问名称 `PDFPDF`，有的可访问性输出会显示 `PDF PDF`，应以当前 DOM 的实际名称定位。
4. 实测点击直接开始本地下载，详情页仍然保留。优先核对浏览器下载结果与目标文件，避免因没有新标签页重复点击。
5. 验证文件大小、可解析性、页数与论文身份。PDF 中的 DOI、题名或卷期页码可与检索结果比对。

若目标条目只提供外部数据库入口，进入后重新确认权限和全文状态。若需要“文献传递”，先查看该入口展示的条件和表单，申请发送按用户授权执行。本次仅观察这两类入口。
