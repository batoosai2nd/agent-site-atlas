# 检索、筛选与 DOI 定位

输入为主题词、论文题名或 DOI。完成标准是得到符合任务条件的结果，并核对题录身份。

## 主题与分面

1. 在“请输入检索词”文本框输入查询，点击“检索”。从机构图书馆入口发起的搜索也会直接到达结果页。
2. 顶部资源类型栏目可点击“期刊”“图书”“学位论文”等类型。实测点击“期刊”后结果总数随之更新。
3. 左侧分面包括馆藏类型、精炼检索、语言、年份、重要收录和学科等。勾选“检索馆藏电子资源”等条件后，点击“执行限定筛选”。勾选本身尚未完成筛选。
4. 核对选中条件、结果总数和具体条目。实测主题查询从 5,600 条混合结果限定为 2,207 条期刊，再限定馆藏电子资源后为 2,165 条。这些数字只记录当次验证。
5. 结果卡片提供作者、来源、年份、关键词、摘要和获取链接。打开标题详情后核对目标论文。

## 高级检索

1. 点击“高级检索”。表单支持语种、文献类型、多行字段条件、匹配方式、年份，以及馆藏限制。
2. 按 DOI 查论文时，先将文献类型选为“期刊”。从首页直接进入时初始为“全部”，字段菜单中没有 DOI；选择“期刊”后才出现。
3. 第一行字段下拉框可选择题名、作者、关键词、摘要、作者单位、DOI 等。实际页面用可见自定义下拉框覆盖隐藏的原生选项，自动化定位时应选择可见控件，避免命中隐藏 `option`。DOI 位于菜单下部，需要在菜单内部滚动至可见后点击；工具返回点击成功时，字段也可能尚未改变。
4. 核对字段确已变为“DOI”，匹配方式自动切为“精确”。在对应输入框填入完整 DOI，核对期刊、语种和馆藏条件，再点击“检索”。
5. 实测 DOI `10.13234/j.issn.2095-2805.2026.2.233` 返回两条中英文题录，卷期页码对应同一论文。整理结果时按 DOI 识别重复记录。

页面说明高级检索多条件按顺序运算，例如 `(A 或 B) 与 C`。复杂条件应核对页面生成的检索条件及结果。二次检索、排序、年份范围和翻页入口已观察，未逐项执行。
