# 引用内容与题录导出

输入为目标论文及所需格式。完成标准是取得引用内容或导出文件，并核对题名、作者、年份及来源字段。

1. 在论文详情点击“引用”。弹层显示参考文献文本，并提供复制、导出、打印和更多格式。
2. 实测格式入口包括文本、参考文献、查新引文格式、Excel、EndNote、NoteExpress、RefWorks、NoteFirst、BibTex。
3. 点击 `BibTex` 会新开“引用题录”页。左侧为格式列表，正文文本框可读取 BibTeX，顶部提供“复制”“导出”“打印”。
4. 点击“导出”，核对实际保存文件。实测 BibTeX 内容被保存为 `References.txt`，因此应同时检查内容与扩展名。
5. 需要用于文献管理或排版时，核对字段完整性。样本含题名、作者、刊名、`issue`、页码和年份，卷号与 DOI 未出现在导出文本中，引用键也包含作者姓名和空格。具体目标软件的导入与编译兼容性需要另外验证。

## 实测下载差异

2026-11-18 自动化点击“导出”曾跳转到 Chrome 的 `ERR_BLOCKED_BY_CLIENT` 页面。用户在同一环境手动点击后成功下载。随后 agent 核对 `References.txt` 为 369 字节 UTF-8 文本，含 `@article`，题名、年份及页码均与目标论文一致。

遇到同样的自动化反馈时，先检查浏览器下载和本地文件，确认是否已完成。导出未保存时，仍可从引用页读取所需内容，或由用户完成普通下载后核对文件。该现象仅记录此次客户端行为。
