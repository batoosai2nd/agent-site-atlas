# 超星发现

先核对[网站与访问条件](references/site.md)中的机构状态和实测范围，再选择任务。

| 任务 | 指南 |
| --- | --- |
| 主题检索、文献类型和馆藏筛选、DOI 定位 | [检索与筛选](references/search.md) |
| 核对论文详情并下载可访问 PDF | [全文获取](references/fulltext.md) |
| 读取引用，导出题录并核对字段 | [引用与导出](references/citations.md) |

全文来源和访问权限取决于用户当前机构。页面中的获取链接由当前结果提供，按所选文献重新取得。
