# 定位章节内容

输入为课程和章节名称或编号。完成标准是打开目标小节，确认标题，并读取实际正文状态。

1. 在课程菜单点击“章节”，读取 `iframe#frame_content-zj`。顶部显示已完成任务点数量，下面为章、节目录和搜索框。
2. 点击目标小节的链接，核对编号及名称。部分小节名称后还有数字，实际任务类型和完成要求需进入页面查看。
3. 实测小节在当前课程标签页中跳转到 `mooc1.shu.edu.cn`，页面有“章节详情”“返回课程”“上一节”“下一节”，以及右侧目录、讨论、笔记和标注入口。
4. 正文位于 `iframe#iframe`。实测所选小节显示“暂无内容”，应以此状态报告该小节，其他小节仍需分别读取。
5. 通过“返回课程”回到课程菜单。

2026-11-18 已从章节目录进入一个指定小节并核对其空内容状态。视频、测验、笔记、讨论发布和任务点完成未实测。
