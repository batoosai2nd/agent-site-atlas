# 核对作业与考试状态

输入为课程和目标考核或时间范围。先核对班级，再读取列表状态和可见安排。

1. 课程左侧“作业”进入 `iframe#frame_content-zy`，“考试”进入 `iframe#frame_content-ks`。
2. 两类列表都有“全部”“已完成”“未完成”筛选。读取默认选中项，避免把筛选后的空列表解释成整门课没有考核。
3. 作业页实测可显示 `0/0` 和“暂无作业”。考试页既观察到“暂无考试”，也观察到有标题的“已完成”考试条目。
4. 若条目标注“只允许手机APP考试”，记录该设备限制。需要考核日期或规则时，同时查课程“任务”里的通知和课程大纲。
5. 页面未显示截止时间时，明确记录缺失字段。通知的发布或结束时间不能直接作为作业截止时间。
