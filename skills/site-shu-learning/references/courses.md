# 定位课程

输入为课程名称，以及需要时的学期、教师或课程编号。完成标准是进入匹配课程，并在课程页核对名称和班级。

1. 打开教学平台，点击“学习空间”，切换到新标签页。有效登录下可直接进入“我学的课”。[教学平台](https://learning.shu.edu.cn/portal)
2. 在学习空间的 `iframe#frame_content` 内读取当前学期。实测初始页面仅展示当前秋季学期的课程。
3. 点击学期文本，选择目标学期或“全部”。“全部”会同时列出历史课程，可能出现同名、不同教师的多张卡片。
4. 在该框架内的“搜索”文本框输入课程名并按 Enter。实测支持名称搜索，结果仅保留匹配卡片。核对课程编号和教师。
5. 点击卡片的封面链接。实测名称文本 `dt` 本身不会打开课程。需要 DOM 定位时，可将 `li.zmy_item` 限定为包含目标课程名称的卡片，再点击其 `a.zmy_pic`。有同名结果时先补充教师或编号条件。
6. 切换到新开的学生课程标签页，确认左侧课程名。课程任务、作业或考试页中的标题还会显示班级后缀。

课程未出现时，先检查学期、搜索词和“我学的课”是否正确。已结课课程可能有“本课程已结课”覆盖提示，应据实际入口状态报告可访问范围。
