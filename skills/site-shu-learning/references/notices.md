# 阅读通知

输入为课程、通知主题或时间范围。完成标准是核对通知所属课程、标题、发布时间和正文中的实际安排。

## 从课程任务进入

1. 在课程菜单点击“任务”，读取 `iframe#frame_content-hd`。
2. 列表分为 `In progress` 与 `Ended`，条目同时包含签到和通知等类型。按类型和标题定位通知。
3. 点击通知标题，检查新标签页。实测通知正文打开到 `notice.chaoxing.com` 的 `Notification details` 页面。
4. 读取正文和发布时间。任务列表的 `End time` 与通知发布时间是不同字段，课程活动或考试日期又可能写在正文中，应保留字段含义。

实测通知页面有 `Reply` 编辑区和附件上传控件。研究或汇总通知的完成点为读取所需内容，回复属于另一项外部操作。

## 从统一收件箱定位

学习空间左侧“收件箱”在 `iframe#frame_content` 中显示全站通知列表。实测界面有 `All`、`Search`、搜索按钮、`Sent`、`Compose` 和发件时间。可先凭标题、发件人和时间定位目标，再打开正文核对所属课程。
