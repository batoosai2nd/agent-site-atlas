# 网站与访问环境

公开入口为上海大学本科生院网络教学平台。登录状态有效时，首页显示“学习空间”。点击后新开上海大学学习空间，左侧有“课程”“智播课堂”“新版云盘”“收件箱”。本包覆盖学生端课程与通知。[教学平台](https://learning.shu.edu.cn/portal) · [学习空间](https://imooc.shu.edu.cn/)

实测环境为 2026-11-18、Windows Chrome、已有学校学生登录状态。门户和课程主要为中文，任务列表和收件箱包含英文控件。此次登录前的统一身份认证过程没有重新执行。

这些框架标识来自现场页面。先通过当前 DOM 或可访问性树确认再使用。正文在 iframe 内时，顶层页面读取可能只返回导航。

网址中的 `t`、课程或班级编号、`cpi`、`enc`、`ckenc`、`s` 等参数随课程或会话变化。复用当前页面链接，公开指南只保留通用入口和控件位置。
