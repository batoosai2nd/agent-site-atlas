# 课程资料预览与单文件下载

输入为课程和文件名或内容线索。下载完成以本地文件存在、类型可解析且与目标资料对应为准。

1. 在目标课程左侧点击“资料”，读取 `iframe#frame_content-zl`。
2. 资料列表有“全部文件”路径、搜索框，以及文件名、大小、创建者、创建日期。文件夹大小显示为横线，文件条目可显示扩展名和大小。先核对目标版本及日期。
3. 点击文件名进入当前页面内的预览弹层。实测 DOCX 被转换成分页预览，标题中的空格可能显示为 `+`。预览成功后仍需执行下载以取得原文件。
4. 使用预览右下方的下载图标。实测文档预览在资料框架内的子 iframe，其 `src` 包含 `mooc2-resource-index.html`，下载链接为 `a#downloadUrl`。若工具无法用语义名称找到无文本图标，先检查当前 DOM 或截图，再定位这个实际可见的控件。
5. 实测通过浏览器工具的媒体下载操作读取该链接，成功保存原始 DOCX。也可使用当前浏览器支持的普通下载控件。完成后核对文件名、文件大小与可解析性。
6. 预览弹层右上角可关闭，实测控件为资料框架内的 `a.closePop`。
