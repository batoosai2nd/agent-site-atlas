# 上海大学学生学习空间

从[网站与访问环境](references/site.md)确认课程归属和当前学期，再选择任务指南。

| 任务 | 指南 |
| --- | --- |
| 从门户进入学习空间，查找当前或历史课程 | [课程定位](references/courses.md) |
| 预览和下载课程大纲、讲义等单个文件 | [课程资料](references/materials.md) |
| 阅读课程任务中的通知，定位统一收件箱 | [通知](references/notices.md) |
| 查作业、考试列表和相关安排 | [考核状态](references/assessments.md) |
| 查章节目录，定位指定小节 | [章节导航](references/chapters.md) |

页面通常包含跨域 iframe，课程和通知还会打开新标签页。每次切换后根据当前页面确认标签页和框架。学习空间里的课程、班级和签名参数由当前会话提供，使用页面上的入口进入。
