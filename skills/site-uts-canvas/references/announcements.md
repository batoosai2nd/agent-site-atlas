# 查找并阅读课程公告

1. 核对科目与教学期，从该卡片的 **Announcements** 快捷链接或课程菜单进入公告列表。首页的 **Recent announcements** 和 Dashboard 的 **To do** 可用于找线索；要查某段时间的公告，进入课程内标有 **Announcements** 的列表。
2. 确认 **Announcement filter** 为 **All**。要找某条公告，可在 **Search discussions by title** 输入标题关键词；这个搜索框按标题搜索。若只知道正文中的词，先清空标题筛选，按日期浏览并打开候选条目。有后续页时继续到所需日期范围。不要把“未读”数量当成公告总数。
3. 在条目旁核对 **Posted on**。点击标题，等正文出现，读取实际要求、适用对象和文内链接。涉及考核时，将公告发布日期、正文提及的活动时间、以及所指向作业页的截止时间分别记录。若公告指向最新考核说明，接着打开[作业详情](assessments.md)。
4. 回复用户时给出科目、公告标题、发布日期和与问题有关的变化。仅检索了部分页时说明核查范围。供用户私下使用时可给出普通课程页面链接；公开网站手册不收录个人课程链接或公告全文。

2026-11-16 从目标课程卡片进入完整列表，观察到 All、标题搜索和 Posted on，打开其中一条公告并读到它指向 Assignments 的说明。该次试用未用搜索框过滤或翻页。
