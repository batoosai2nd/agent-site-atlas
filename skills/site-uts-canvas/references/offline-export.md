# 取得并验收课程离线包

**先确定要已有版本还是最新版本。** 从课程 **Modules** 看 **Export Course Content** 附近是否显示 **Last export**。本次界面中，点 Last export 后的日期进入 **Exported package history**，再点匹配日期的记录才会开始下载 ZIP。若只需已有版本，这条路径可以复用上次导出。

若用户需要重新生成且课程提供 **Export Course Content**，点击一次，等待进度完成，检查本次浏览器下载和导出历史。历史试用中，完成时可自动下载，历史条目有时稍晚出现。进度消失后，先查文件及历史，再决定是否重试。课程负责人决定是否提供导出，内容范围因课程而异。[UTS Canvas FAQ](https://www.uts.edu.au/for-students/current-students/managing-your-course/using-uts-systems/software-available-students/canvas/canvas-student-guide/canvas-faq)

**在本地验收。**

1. 获取此次下载事件的文件路径，打开 ZIP 并检查 CRC。包内可能有一层以课程和时间命名的外层目录，查找实际的 `index.html` 以及 `viewer/files/`，不要假定它们位于 ZIP 根目录。
2. 对用户需要的资料，按模块或作业及文件名定位成员。对照链接时解码路径中的百分号编码，并以链接所在文件的目录解析相对路径。同名文件有多份时，核对所在目录，必要时与在线单独下载的文件进行比较。
3. 选一份目标 PDF，从正常的模块预览页[单独下载](materials.md)。以 SHA-256 比较两份文件，并确认 PDF 可打开。记录“目标文件一致”；单一文件一致和 ZIP 完整性检查不能证明所有资料均被导出。
4. 若入口或作业说明提到的附件在包内不存在，在当前仍可访问的网页上打开相应附件并核对。将补充文件单独保存，保留原始 ZIP，记录补充来源。若文件锁定或链接失效，如实列出缺项。下载只用于获准的学习用途。

若任务要求验证“能离线浏览”，把完整目录结构解压到新的本地目录，用浏览器打开入口，在离线状态下点开一份目标附件。单独打开 PDF 只能验证文件本身可读。

2026-11-16 从历史记录取回一个已有 ZIP，检查其完整性、入口文件和模块附件，并确认其中一份 PDF 与独立下载的 PDF 具有相同的 SHA-256。独立试用也复核了入口结构和该 PDF；本次未测试浏览器断网导航。以往试用验证过生成新包，且曾发现一个可在网页取得的附件缺失。
