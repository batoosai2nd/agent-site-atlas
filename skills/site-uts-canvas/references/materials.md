# 下载模块文件并核对本地版本

1. 进入目标科目的 **Modules**，也可以从课程首页点击 **Go to Modules**。在 **Course modules** 中找到对应周次或主题，必要时展开分组，核对条目类型与文件名。一次模块查询只覆盖该课程里已发布、当前可见的内容。
2. 点击文件条目，文件预览页标题应与目标相符。点预览页的 **Download + 文件名**。若工具支持下载事件，在点击前监听，随后从事件取得实际保存位置。这可避免把浏览器打开预览、或下载目录里的同名旧文件，误作本次下载。
3. 确认新文件存在，用相应阅读器实际打开。对于 PDF 可用 PDF 解析器检查有可读页面。需要比对版本时计算 SHA-256，并记录相对文件名及核对日期；大小和更新时间可用于筛查，不能独立证明内容变化。
4. 用户有批注时，保留上一版服务器原件的摘要与当前本地批注版的摘要。新下载若与上一版原件相同，保留批注版。两次原件摘要不同，则另存新版并标明旧批注的来源。若只有批注版，且与新下载文件不同，记录“尚不能判断源文件是否更新”，保留两份。
5. 若课程未提供 Files 菜单，可以在 Modules 或作业正文中查看当前正常显示的文件入口。遇锁定或拒绝提示，记录具体文件及状态。需要多份文件时可转入[离线导出](offline-export.md)。

2026-11-16 从课程模块打开一份 PDF，点击 Download 后从下载事件取得落盘位置，验证 PDF 可解析，并确认它与同一课程离线包里的文件内容一致。未在本次试用中覆盖全部格式。
