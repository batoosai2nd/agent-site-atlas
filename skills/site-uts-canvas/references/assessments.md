# 核对考核、可用窗口和截止时间

从目标课程进入 **Assignments**。列表中可见 **Search for Assignment**，项目可能按 **Upcoming assignments** 和 **Undated assignments** 等分组。先核对科目和详情标题，再读详情；To do 上的一行摘要不足以确认全部安排。

| 页面证据 | 可回答的问题 |
| --- | --- |
| **Due** | Canvas 登记的截止时间。若没有值，记录“页面未列截止日期”。 |
| **Available after / Available from**、**Until / Available until**、**Closed** | 平台何时允许访问或提交。若正文显示 **locked until**，记录可见的解锁提示。 |
| 公告或作业说明中的课堂日期、时间、地点 | 教师公布的活动安排。与 Canvas 窗口不一致时，保留两种来源和原文中的时间含义，指出待确认的具体问题。 |

打开可见的作业详情。若显示开放时间与截止时间，分别记录两个字段，并保留显示时区或注明未标明。“Undated”分组中也可能有仍显示“Closed”的任务。若详情仍锁定，到可见的日期、分值、状态和标题为止；不要启动尝试来调查题目。

已开放的详情若附有 brief，打开当前可见附件，核对版本、要求和日期后再与旧笔记比对。历史试用曾在最新 brief 中见到更新的考核要求。若所需附件不可访问，将其列为缺项。报告应能逐项回答“何时开放、何时截止、教师另行安排了什么、哪些仍待确认”。
