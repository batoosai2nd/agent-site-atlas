# 入口与课程范围

从 [UTS Canvas](https://canvas.uts.edu.au/) 进入。已有 UTS 单点登录的浏览器可直接显示 **Dashboard**。如需账号或多因素验证，由用户完成常规登录。Dashboard 卡片显示科目和教学期。在仪表板找不到时，UTS 指南给出的入口是全局 **Courses → All Courses**。[UTS 学生指南](https://www.uts.edu.au/for-students/current-students/managing-your-course/using-uts-systems/software-available-students/canvas/canvas-student-guide) · [UTS Canvas FAQ](https://www.uts.edu.au/for-students/current-students/managing-your-course/using-uts-systems/software-available-students/canvas/canvas-student-guide/canvas-faq)

优先从目标课程卡片或课程内的菜单进入。**Global Navigation Menu** 负责全站导航，窄屏课程页还可能有单独的 **Navigation menu**。科目首页也可能提供 **Go to Modules**。部分仪表板卡片在标题下方有 Announcements 或 Assignments 快捷链接，卡片显示哪些入口随科目而异。右侧的 To do 混合多门课，打开条目后要再核对科目。

- **本次现场验证，2026-11-16。** Windows、Chrome、英文学生界面、已授权的课程。完成公告列表到正文、作业列表到锁定详情、模块单文件下载，以及从导出历史下载已有 ZIP。单文件与 ZIP 中对应 PDF 可解析且 SHA-256 一致。
- **以往学生界面记录，2026-10 至 2026-11。** 曾生成新离线包，也观察到附件在在线作业页可见、离线包却缺少对应文件的情形。课程菜单、公告数量、可导出内容和可用窗口都可能因科目而异。

记录核查日期、课程归属和页面显示的时区；不确定时写“页面未标明时区”。若需换算，先确认 Canvas 账号显示时区和用户所需时区，再按目标日期换算。悉尼存在夏令时，不应全年套用固定时差。公开指南只引用平台入口与 UTS 帮助文档。
