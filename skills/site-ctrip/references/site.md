# 网站与验证环境

## 范围

2026-11-16 在 Windows Chrome 中文桌面站、已有登录会话中验证酒店查询、日期与入住人数、位置和早餐筛选、房型条件及差评阅读。指南覆盖酒店选购前的信息查询。机票、火车票、度假套餐及订单结算链路仍待研究。

从 [携程首页](https://www.ctrip.com/)进入酒店查询，结果和详情位于 hotels.ctrip.com。酒店名可打开新的详情标签页，详情地址常带日期、入住人数及筛选参数。公共引用优先使用页面提供的酒店固定链接。

直接打开酒店固定链接会使用当前默认日期和人数。比较价格前重新设置用户条件，并检查入住、退房和间夜数。

## 重要页面行为

- 顶部全站搜索和酒店查询框各有用途，日期与人数必须在酒店搜索区域设置。
- 日历按酒店当地时间解释入住和退房日期。双月日历会出现同名日期，应同时核对月份和已选日期。
- “免费取消”筛选后的列表仍可能出现“订单确认后30分钟内免费取消”的报价。以具体房价政策核对用户要求。
- 酒店详情先显示匹配筛选的房型，也可能显示带“以下房型或未能满足您所有需求”提示的其他房型。每项报价都需重新核对。
- 详情存在多组日期、人数和价格控件，操作时限定酒店搜索区域或对应房型。
- 研究时评分的无障碍文字出现“4.5 out of 10”，页面主文字显示 4.5。交付时核对可见评分和量纲。

价格、库存、会员优惠与评论数量随会话和时间变化。指南中的酒店用于说明已测试路径。
