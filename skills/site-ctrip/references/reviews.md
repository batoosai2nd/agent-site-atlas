# 住客点评阅读

## 输入与完成标准

输入目标酒店和重点问题，例如隔音、接送机或卫生。完成时读取相关点评及其入住背景，注明筛选范围，支持判断的内容与酒店说明分别引用。

## 操作

1. 在详情找到“显示所有…条点评”按钮或“点评”区域。
2. 可选择所有点评、有图、视频、差评及当前热门提及。数量动态变化，应使用当前名称或文字前缀定位。
3. 选择筛选后读取完整点评面板。实测点击“差评 (102)”打开覆盖层，选中按钮显示“差评(102)”及关闭标记。
4. 逐条核对房型、入住年月、出游类型、评分、发布日和酒店回复。有“展开更多”时按当前条目展开并确认新增文本。
5. 如需换房型、出游类型或排序，先检查面板上的当前筛选。研究时观察到“所有房型”“所有出游类型”和“最相关”。
6. 交付时概括多个相关样本，并说明选择了哪类点评及日期范围。

2026-11-16 在小香樟花园酒店打开差评面板，读取不同房型的入住信息、点评发布时间及酒店回复。评论文本和图片可在该面板中查看。房型筛选、排序切换及完整分页仍待验证。
