# 酒店搜索与筛选

## 输入与完成标准

输入城市或具体位置、入住退房日期、房间数、成人数，以及有儿童时的年龄。完成时搜索条件与用户需求一致，并取得能进入详情核对的候选酒店。

## 操作

1. 在首页酒店模块填写目的地并选择对应建议项。研究时可用输入框 ID 为 hotels-destination，位置或品牌关键字字段为 keyword。使用前结合当前页面确认。
2. 打开日期控件，先选择入住日，再选择退房日。双月日历应限定月份面板，检查天数、月份、年份与间夜数。
3. 打开人数按钮，分别设置房间、成人、儿童。成人行的加减控件可能仅有图标，此时在“成人”所在行中定位加号或使用最新截图。确认后核对按钮汇总。
4. 点击酒店模块内的“搜索”。进入结果页后，在 Search properties 区域核对目的地、日期及“1间, 2成人, 0儿童”等汇总。
5. 根据需求操作早餐、位置、评分、支付方式或服务筛选。实测“免费取消”为 checkbox，“双份早餐”和“上海虹桥站”为 radio。
6. 每次筛选后重新读取勾选状态和结果。结果数量与列表会自动更新。
7. 从符合需求的酒店名或其卡片内“查看详情”进入详情，检查新标签页与条件继承。

## 已验证

2026-11-16 查询上海，入住 2026-11-20、退房 2026-11-21，1 间、2 成人、0 儿童。逐项勾选免费取消、双份早餐、上海虹桥站，结果数量随条件减少。打开小香樟花园酒店的新标签页，日期和入住人数正确继承。

本次观察到价格、星钻级、评分、点评数、品牌及更多设施筛选入口。上述三项以外的筛选、排序切换和儿童年龄设置仍待验证。

## 结果解释

位置筛选后的酒店仍需检查实际距离和交通方式。结果卡的“起”价需要进入具体房型报价核对。筛选和结果解释沿用用户明确的预算及取消期限。
