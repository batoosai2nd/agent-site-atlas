# Citation export / 题录与引用

Evidence: documented in sections 1.4.2 and 1.6 of the [official 全球学术快报 2.0 / KNS 8.0 manual](https://piccache.cnki.net/index/helper/manuals.html). This helper is linked by the current advanced form, but its update date is unknown and this workflow has not been run in the recorded browser session.

Inputs: identified record(s), requested citation style or machine-readable format, output destination. Output: correct citations or a verified export file for exactly those records.

1. Verify the records' full titles, authors and sources. On a result list, select only the requested records before opening the currently available export action.
2. The manual's result route is `导出与分析` into bibliographic export/management. Its documented default is GB/T 7714-2015. A detail page can provide `引用`, with `更多引用格式` leading to additional choices. Locate the actual current labels; do not treat these historical labels as guaranteed selectors.
3. Inspect the available style/file formats and select the user's requested one. A GB/T formatted text citation and an EndNote/RIS/BibTeX data file serve different outputs; do not claim an unobserved format is available.
4. Export or copy using the current UI. Validate title, author, source, year and record count against the selection, and confirm a saved file before reporting a file path. Preserve metadata the site actually supplies; do not invent missing page numbers or DOI values.
5. If export requires verification/login or a requested format is absent, report the specific unfinished step. A manually converted citation should be identified as a conversion, with bibliographic checks, rather than claimed as a native site export.

Do not copy institutional account text or session-bearing URLs into shared citation examples. Downloads/exports of article content remain subject to their own access and licensing; this manual's license covers the original instructions only.
