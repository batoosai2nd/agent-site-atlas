# Article and full text / 文献与全文

Inputs: an identified CNKI paper, requested PDF/CAJ/HTML format and optional destination. Output: a verified file and matching citation metadata, or the precise missing entitlement/verification step.

## Procedure

1. Open the selected record's own title link. Check title, authors, source, publication date and DOI when available. A result/recommendation card alone may truncate these details.
2. Inspect the download/read actions on that record. The live recommendation cards exposed `下载`, `HTML阅读` and `CNKI AI阅读`; the last is a separate AI-reading product. Their `下载` controls showed `未登录` in the observed session.
3. Use the available official download action. The KNS 8.0 manual documents `CAJ下载`, `PDF下载` and `HTML阅读` subject to content/access, with CAJViewer used for CAJ. If the current page offers formats, select the user's requested format; report which formats are actually available. Do not assume every item offers PDF or that changing an extension converts CAJ to PDF. For foreign partner records, the manual describes an original-source link; verify the destination and continue with that publisher's access conditions.
4. Follow the authorized login/institution route if necessary. A personal account and institutional entitlement are separate conditions. Do not copy another user's cookies or assume a shared knowledge pack transfers access.
5. Inspect the resulting state: file download, reader, login/order screen, unavailable full text or CAPTCHA. A link to `bar.cnki.net/bar/download/order` is a delivery/order entry, not proof of a free file or completed download.
6. When a file is obtained, verify its actual type and readability using available local tools, and match its title/author or DOI to the record. Report the real saved path and format. For a reader-only result, say that the document is open for reading; do not call it a local download.

## Access and interruption branches

| Current state | Handling |
| --- | --- |
| `未登录` / institutional login | Request or use authorized access in the current user's session |
| CAPTCHA / `安全验证` | Ask for user assistance under host policy and resume on the same task after verification |
| Recharge, purchase or order confirmation | Report the access cost/requirement; obtain the user's transaction authorization where required |
| CAJ only, user requested PDF | Explain the available format; ask before changing the requested output or use a legitimate publisher copy when authorized |
| Download reported but file unreadable | Inspect whether it is an HTML login/challenge page; do not rename it into a claimed PDF |
| Article unavailable | Report the missing full text, with bibliographic metadata and the official record link |

Preserve official canonical record links for reuse. Dynamic download URLs, query tokens and authentication material belong only to the current session. Never publish downloaded paper contents as part of this MIT-licensed manual.
