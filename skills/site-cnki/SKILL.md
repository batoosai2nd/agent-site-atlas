# 中国知网 / CNKI

Read [site context](references/site.md), then the workflow matching the task:

| Task | Read |
| --- | --- |
| Search terms, exact title, author, find a paper | [Search](references/search.md) |
| Combine fields, publication date, source and OA conditions | [Advanced search](references/advanced.md) |

Use the current agent's browser tools and the user's intended CNKI environment. Check the actual URL and page before applying remembered controls; mainland and overseas/institution-proxy interfaces can differ. Read only the references needed for the current step.

This pack has partial live coverage: homepage and advanced form were inspected, while CAPTCHA prevented a completed search/download run. Its guidance must not be presented as an already executed query or successful download. Use the visible state to finish the task, and report the actual blocker when user action is required.

Match the requested title/author/year before downloading. Keep current cookies, login data, institution names, signed links and paper files out of shared knowledge-pack updates.
