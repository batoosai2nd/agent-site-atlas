# 可访问全文下载

## 输入与完成标准

输入已识别的论文和用户要求的版本。成功时应有已保存且能打开的 PDF，标题、作者与目标一致，并在可取得时核对 DOI。

## 操作

1. 在正确结果上查看右侧或旁边的 [PDF] 来源链接。需要更换版本时先进入 All … versions。
2. 点击链接，观察原标签页及新标签页。实测 NeurIPS PDF 在原标签页打开。
3. 若进入来源站文章页，使用其当前可用的 PDF 入口。机构访问问题沿当前授权图书馆入口处理。
4. 浏览器 PDF 阅读器的正文可能无法通过网页 DOM 读取。使用浏览器可见的下载或保存控件。实测在已聚焦的 Chrome PDF 页按 Ctrl+S 可打开保存对话框。
5. 保存至用户指定位置，等待文件完成。核对文件可以解析、页数合理、首页标题和作者符合目标。访问错误页或登录页需要返回上一步解决访问条件。
