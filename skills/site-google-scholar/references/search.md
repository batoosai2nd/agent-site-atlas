# 论文检索与版本定位

## 输入与完成标准

输入论文标题、作者或主题，以及用户要求的年份和版本。完成时给出能与用户目标对应的记录，至少核对标题、作者、发表年份和来源，并说明选择的版本。

## 操作

1. 在 Scholar 首页 Search 或“搜索”文本框输入题目。已知完整标题时可用双引号包围，例如 `"Attention is all you need"`。提交后读取结果页。
2. 结合主标题与作者、年份、来源识别目标。结果可能包含引用记录、预印本、正式出版物或其他题名相近的材料。
3. 根据用户条件读取时间和排序控件的当前状态。2026-11-16 观察到 include citations 默认勾选、include patents 默认未勾选。将这些状态连同查询范围用于解释结果。
4. 如需其他来源，在目标结果内选择 All … versions。重新读取版本页，逐条核对书目信息和来源域名。
5. 根据任务进入 Cite、结果侧边的 PDF 或来源标题链接。跳转后核对页面身份。

## 已验证

2026-11-16 检索 Attention is all you need，定位 Vaswani 等人的 2017 年 NeurIPS 论文，打开 All 26 versions 并检查来源列表。版本入口的数量和版本页估算的结果数量存在差异，应分别保留其页面含义。当前结果的出版方 PDF 链接随后成功到达全文。

上述样例验证了标题检索和版本阅读。时间筛选、排序切换及高级检索的控件已观察，具体操作结果仍待验证。

## 页面变化时

结果列表重新排序后，重新定位论文卡片。匹配 Cited by 或 All … versions 时使用文字前缀并核对所在论文，避免依赖固定数值。遇到访问验证时保留查询条件，交由用户完成后从当前页继续。
