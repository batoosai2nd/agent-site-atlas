# 从数据需求找到单表

先确定研究对象及观察频率。一只证券每月一条的收益率、整个市场每月的收益率、证券的日行情分别属于不同的数据表。

1. 从[平台首页](https://data.csmar.com/)进入顶部“数据中心”，选择“单表查询”。
2. 在系列列表选“股票市场系列”，再选数据库“股票市场交易”。展开“个股交易数据”，选择“月个股回报率文件”。完整路径为 **数据中心 → 单表查询 → 股票市场系列 → 股票市场交易 → 个股交易数据 → 月个股回报率文件**。
3. 在表单核对当前表名、“时间设置”里的时间基准及“字段设置”。月表代码为 `TRD_Mnth`，时间基准是“交易月份”，粒度为证券 × 月份。这三项对上才算找到目标表。指明的月份、证券及红利口径交由[下载指南](monthly-returns.md)处理。

在先前核对的财务报表目录中，资产负债表的路径为 **数据中心 → 单表查询 → 公司研究系列 → 财务报表 → 资产负债表 → 资产负债表**。前一个同名项是分类，后一个是数据表。遇到不同版本或权限范围，展开当前数据库并以最后一级的表标题和字段为准。只看到系列或数据库时，仍需定位具体数据表。
