# 网站与验证环境

入口是 [CSMAR 数据平台](https://data.csmar.com/)。桌面简体中文界面从“数据中心”进入“单表查询”。目录显示哪些表、网页是否允许下载、个人账号能通过 Python 接口查询哪些库，需要分别核对。

| 日期 | 环境与证据 |
| --- | --- |
| 2026-11-16 | Windows、Chrome、已登录且能访问样表的网页会话。从首页定位“月个股回报率文件”，预览一只证券三个月的数据，保存结果页提供的 ZIP，并读取其中的 CSV。 |
| 2026-10-21 | 在已登录的中文界面展开过多个系列与数据库。目录指南中的财务报表示例来自这次观察。 |
| 2026-11-16 | 核对[官方 Python 接口文档](https://data.csmar.com/static/document/Python-zh.html)，在 Windows 本地导入 SDK 并创建客户端。在线登录、授权库枚举和在线 API 查询属于文档覆盖。 |

首页与嵌入的查询界面可能分别有“单表查询”字样。点顶部“数据中心”，以同时看见“单表查询”、系列列表和数据库名确认已进入目录。部分浏览器工具会将内嵌页面作为独立 frame 展示，此时在实际显示系列或查询表单的 frame 中操作。

下载结果新页可能含任务参数，ZIP 链接、文件名及附件可能带有使用范围或机构信息。分享操作指南时链接到平台首页或公开文档，原始导出留在获准使用的环境。
