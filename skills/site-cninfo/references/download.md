# 公告 PDF 下载

## 输入与完成标准

从已核对公司与报告期的公告详情开始。完成时存在可打开的 PDF，首页公司、报告标题和报告年度与详情一致。

## 操作

1. 在详情页记录披露日期、完整标题及证券代码。下载目标应对应当前公告详情。
2. 点击“公告下载”。观察是否出现新标签、浏览器下载或保存对话框。
3. 如果页面没有变化，检查浏览器下载状态和实际下载目录。实测文件直接保存到浏览器配置的下载目录。
4. 等待下载完成，打开文件或使用本地 PDF 解析工具检查页数与首页信息。
5. 交付原始公告详情链接、保存路径和报告期。出现同名文件时核对最新文件的时间与内容。
