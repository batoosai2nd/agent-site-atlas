# 网站与验证环境

## 范围

2026-11-16 在 Windows Chrome 中文桌面界面及已有登录会话中完成公司定位、定期报告选择、公告详情与年报 PDF 下载。报告检索指南用于取得公司原始披露材料。

[巨潮资讯首页](https://www.cninfo.com.cn/new/index)提供代码、简称、拼音与关键字输入框。选择证券建议项后进入公司披露页。公司页包含最新公告、定期报告、调研入口。

## 导航特征

- 公司代码搜索会显示证券类型、代码与简称，选择完整建议项可确定主体。
- 定期报告入口在公司页内切换，实测地址出现 #periodicReports。
- 报告标题打开新的公告详情标签页。
- 公告详情包含披露日期、公司、标题和公告下载。PDF 内嵌阅读器可能缺少可用网页文本。
- 公告下载可以直接保存文件，详情页表面保持原状。以浏览器下载状态和实际文件判断完成。

本次验证了 A 股公司年报全文。最新公告的标题、分类、起止日期控件已观察，其组合筛选仍待验证。
