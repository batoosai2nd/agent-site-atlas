# CNINFO 巨潮资讯

先读取[网站与验证环境](references/site.md)，再选择当前任务对应的指南。

| 任务 | 指南 |
| --- | --- |
| 通过代码建议项进入公司页，查找对应报告年度的全文。 | [公司与定期报告](references/reports.md) |
| 从公告详情保存 PDF，核对公司、报告期、披露日期与文件内容。 | [公告 PDF 下载](references/download.md) |

使用当前浏览器中观察到的控件执行任务，用户指定的条件优先于指南中的样例。每条流程的验证范围与完成标准记录在对应指南中。
